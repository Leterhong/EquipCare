## 4. 各中心重构明细

### 4.1 驾驶舱（工作台）— 五层信息架构

1. **欢迎区**：时段问候 + 日期 + 快捷操作
2. **4 核心指标卡**：设备总数 / 待派工单 / 今日巡检 / 本月成本（真实接口数据，无假趋势）
3. **双列图表**：9 张 ECharts（状态环形、故障趋势折线、工单状态、巡检完成率、成本趋势、故障类型/设备/人员排行、备件消耗排行）
4. **14 指标总览**：设备 4 + 巡检 2 + 工单 5（含 MTTR/MTBF）+ 备件 3
5. **动态流**：最新异常 + 工单动态

后端仅新增 `DashboardMapper.selectSparePartRank`（只读 SQL 聚合，并入既有 `/api/dashboard/charts` 响应，`sparePartRank` 字段向后兼容）。

### 4.2 设备资产中心

- 列表页顶部 4 张统计卡（在役 / 维修中 / 停用 / 报废），点击即筛选
- 详情页 6 Tab：基本信息 / 图片与附件 / 巡检记录 / 维修记录 / 备件消耗 / **生命周期时间线**（新增）

### 4.3 巡检中心

- **任务列表 + 巡检日历双视图 Tab**：日历组件抽为可嵌入的 `renderCalendarView`（独立日历页保留），首次切换懒加载
- **状态筛选标签化**：全部 / 待执行 / 执行中 / 已提交 / 已过期 chips，与状态下拉双向同步
- **执行页卡片式增强**：判定完成绿序号、异常红左条、「定位下一项未判定」一键跳转、提交校验失败自动滚动定位并高亮出错卡片
- 移动端：判定按钮横排等宽、卡片元信息纵排

### 4.4 维修工单中心

- **表格 + 看板双模式**：看板五列（待派单 / 待接单 / 维修中 / 待验收 / 已完成），各列独立查询、仅展示不拖拽（状态机只能由动作推进，页面有明示）
- 详情独立页：头部「← 返回列表」+ 状态徽标；概况与故障现场双栏（1.6fr/1fr，窄屏叠放）；派单 / 维修 / 验收 / 备件 / 评价 / 巡检来源分区

### 4.5 备品备件 + 运维分析

- 库存低于安全库存：数字浅橙加粗 + 「低于安全库存」琥珀标签 + 整行浅橙背景（红色留给更强信号）
- 顺手修复 6 个文件 renderTable 列定义 `{header:}`→`{title:}` 的表头空白问题（spare-stock / health-list / sla-monitor / spare-alert / spare-part / spare-txn）
- 运维分析（SLA 监控 / 健康排名）沿用统一浅色规范，无 ECharts 深色残留
