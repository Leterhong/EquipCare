## 1. 传输层

- [ ] **HTTPS**：`deploy/nginx.conf` 尾部附 443 启用模板（证书挂载 / TLS1.2+ / HSTS）

## 2. 网关层（deploy/nginx.conf 已内置）

- [x] 登录限流 `auth_login` 10r/m + burst 5（与应用层连续失败锁定双通道）

- [x] 一般 API `api_general` 30r/s burst 60
- [ ] 按需调整速率并压测验证
- [ ] 429 响应接入前端提示（现已返回标准 429）

## 3. 应用配置

- [ ] `EQUIPCARE_JWT_SECRET`：≥32 字节随机值（**ProdSecurityGuard 会拒绝默认密钥启动**）
- [ ] `EQUIPCARE_CORS_ALLOWED_ORIGINS`：收敛为前端域名（默认 `*` 已关闭 credentials）
- [ ] MySQL `EQUIPCARE_APP_PASSWORD` / `REDIS_PASSWORD`：强口令，拒绝示例值
- [ ] `EQUIPCARE_BOOTSTRAP_ENABLED=false`（管理员创建完成后立即关闭）
- [ ] `SPRING_PROFILES_ACTIVE=prod`（compose 已默认；关闭 SQL 打印与 Swagger）
- [ ] AI / 通知外发等可选功能按需开启，Key 全部走环境变量

## 4. 数据层
