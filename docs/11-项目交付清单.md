## 四、已知问题（如实列出）

1. `application.yml` 保留开发便利默认值（DB 密码默认 `123456` 等），均可被环境变量覆盖；生产 compose 用 `:?` 强制注入，但 yml 本身的弱默认建议后续归零。
2. Docker 交付物未经容器级实测（原因见上）；首次构建如遇镜像层问题按部署文档排查或反馈。
3. 3 个已实现但未挂前端的运维接口（设备维修/巡检历史、健康批量重算）。
4. 前端技术栈为零依赖原生 ES Module，与阶段一规划文档的 Vue 3 + Vite 不一致（阶段三起如实披露，性能与可演示性达标，迁移与否留待人工裁决）。
5. 站内通知为 30 秒轮询，无 WebSocket 推送；无邮件/企微外发通道。
6. 本机 Redis 为 Windows 5.0 移植版，Lettuce 解析其 INFO 失败，已关闭 redis 健康指示器（容器部署用 redis:7 无此问题）。
