# 巡维云 EquipCare · 旧前端退役计划

| 项 | 内容 |
|---|---|
| 文档编号 | EC-FE-020 |
| 版本 | V1.0 |
| 定位 | 原生 ES Module 前端（static/，28 页）→ Vue 端（equipcare-web，23 页）的退役路线 |

---

## 1. 当前状态

| 前端 | 页面数 | 职责 |
|---|---|---|
| 旧版 static/ | 28 | 全功能（含 5 页未迁移：字典管理、全局搜索、工作台细化、转派完整版 UI、权限矩阵） |
| Vue equipcare-web/ | 23 | 双主闭环（工单/巡检）+ 系统管理只读 + 多租户管理 + AI 副驾 |

两版共存：登录态 localStorage 键互通（`ec_*`），Vue 布局提供「完整功能（旧版）」入口。

## 2. 退役路线（三阶段）

| 阶段 | 内容 | 退出条件 |
|---|---|---|
| T1 冻结功能 | 旧版只修 bug 不加功能（当前所处阶段） | Vue 迁移完成 |
| T2 只读归档 | 旧版入口降级为「历史归档」链接，新用户引导全部走 Vue | Vue 补齐剩余 5 页 + e2e 全覆盖 |
| T3 删除 | 删除 static/js/pages 等，schema 无关联（前端无后端文件） | T2 稳定运行一个迭代 |

## 3. 剩余 5 页迁移要点

| 页面 | 复杂度 | 要点 |
|---|---|---|
| 权限矩阵（角色-权限树勾选） | 高 | el-tree + 角色切换 + 批量保存（PUT 角色权限） |
| 全局搜索 | 中 | 聚合接口已有（设备/工单/任务），顶部搜索框组件化 |
| 字典管理 | 中 | sys_dict（共享表）+ sys_dict_item 双层 CRUD |
| 工作台细化 | 中 | 工单/巡检待办卡片聚合，已有 workbench API |
| 转派完整版 UI | 低 | Vue 详情页派单弹窗已含转派路径，仅缺 AI 推荐以外的字段微调 |

## 4. 退役后清理清单（T3 执行时）

- [ ] 删除 `equipcare-admin/src/main/resources/static/js/pages/`、`js/ui.js`、`js/app.js`、`css/app.css`（保留 index/app 壳 → 重定向 Vue）
- [ ] 删除 `frontend-tests/`（旧版 Vitest，65 项断言已由 Vue 端测试承接）
- [ ] `SecurityConfig` 白名单收敛（`/js/**`、`/css/**`、`/m/**` 按需保留扫码页）
- [ ] README/docs 更新截图与结构说明
- [ ] Vue 端补齐：PWA manifest 迁移 + 摄像头扫码页（m/scan.html 保留——旧版独立页，与 Vue 无关）

## 5. 不可退役项

- `m/scan.html`（移动端扫码落地页）：独立入口，非 SPA 的一部分，长期保留
- `index.html`（登录页）：Vue 端路由含登录页，过渡期保留旧版登录入口直到 T3
