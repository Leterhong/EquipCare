# 巡维云 EquipCare · 现场演示说明文档

> 第九阶段交付物。演示目标：30 分钟内按真实业务闭环向评委/领导展示系统全貌。
> 所有演示均使用真实数据与真实操作，无任何写死或预设效果。

---

## 一、演示前准备（10 分钟）

1. 确认服务可达：浏览器打开 `http://<演示地址>/`，出现深空工业主题登录页。
2. 确认演示账号可登录（账号由需求方在部署时创建；下表为角色与演示路径）：

| 角色 | 演示视角 | 登录后看点 |
|---|---|---|
| 管理员 | 全局管理 | 驾驶舱、派单、验收、系统管理 |
| 巡检员 | 现场作业 | 巡检任务执行、异常上报 |
| 维修工 | 报修处理 | 工作台、维修记录、照片上传 |
| 验收员 | 质量把关 | 验收通过/退回 |

3. 准备第二屏（手机）演示扫码：连接与演示机同一网络，确认 `EQUIPCARE_SCAN_BASE_URL` 为该网络可达地址。

## 二、演示动线（30 分钟）

### 第一幕 · 登录与驾驶舱（5 分钟）——「一屏看清设备家底」

1. 管理员登录（口令输入时说明：BCrypt 加密存储，数据库中无明文）。
2. **驾驶舱**：14 项 KPI + 8 张 ECharts 图表。重点讲三处：
   - 设备健康率与健康分（点击设备可下钻到健康详情，八项扣分逐项可解释）；
   - MTTR/MTBF 有明确计算口径（口径写在页面副标题与 README）；
   - 切换「本月/近 30 天」时间范围，图表实时变化——数据全部来自后端接口，无写死。
3. 演示**顶栏三件套**：全局搜索输入设备名关键字（设备/工单/备件三域并行命中）、消息铃铛红点、头像菜单退出。

### 第二幕 · 设备资产与二维码（5 分钟）——「一物一码」

1. 设备档案列表 → 新增设备（演示表单校验：资产编号唯一性）。
2. 设备详情 → 二维码 → **手机扫码**打开落地页：展示设备档案、维修历史、巡检历史。
   - 顺带说明安全设计：二维码只含随机令牌，不含账号口令，扫码需登录权限。

### 第三幕 · 巡检闭环（7 分钟）——「异常自动变工单」

1. 切巡检员账号 → 巡检任务 → 执行巡检：
   - 逐项判定「正常/异常/跳过」；演示**必检项不能跳过**、异常必填说明、数值超区间不能判正常（前端先挡，后端再校验）。
2. 提交后系统自动判定异常项 → 生成异常单 → **自动转维修工单**（演示异常单与工单的关联）。
3. 展示巡检日历与完成率统计。

### 第四幕 · 维修工单闭环（8 分钟）——「7 状态 × 12 动作全流转」

1. 管理员在派单工作台把工单派给维修工（SLA 时限自动计算）。
2. 切维修工账号 → 工作台 → 接单 → 开始维修 → 填写维修记录 → **上传维修后照片** → 提交验收。
   - 亮点：并发接单只有一个成功（状态机 CAS 保证）；备件不足时提交验收会被阻塞（备件关联）。
3. 切验收员账号 → 验收：先演示**验收退回**（工单回到维修中），维修工再提交，最后**验收通过**。
4. 打开工单时间线：10+ 节点全程可溯，每次流转都有操作人、时间戳与审计日志。

### 第五幕 · 备件与运营分析（3 分钟）

1. 备件入库/出库：流水记录变动前后库存快照；演示库存不足出库被拒绝（422）。
2. SLA 预警中心：超时工单红黄牌；库存预警列表。
3. Excel 导出：导出设备清单，现场打开 xlsx。

### 收尾（2 分钟）

- 系统管理：53+ 权限码清单、角色授权矩阵、操作审计日志（明文密码脱敏）。
- 说明：171 后端测试 + 60 前端测试 + 39 接口符合性测试全部通过（详见 `docs/06-功能测试报告.md`）。

## 三、可演示的「拒绝场景」（体现严谨性）

评委质疑数据真实性时，现场演示：

1. 未登录直接访问 `http://<地址>/api/asset/equipment` → 401。
2. 巡检员点「删除设备」→ 403 无权限拦截页。
3. 建单不选工单等级 → 422 明确报错提示。
4. 驾驶舱切换到无数据的未来时间段 → 显示「暂无数据」，不编造指标。

## 四、常见演示事故预案

| 状况 | 处置 |
|---|---|
| 登录页打不开 | `docker compose ps` 看容器状态；`docker compose logs -f backend` 找异常 |
| 演示数据被改乱 | 重新执行 `database/seed.sql` 演示数据段，或用昨日备份恢复 |
| 扫码打不开 | 演示机与手机是否同网段；`EQUIPCARE_SCAN_BASE_URL` 是否为演示机 IP |
| 图表空白 | 时间范围切回「本月」；确认库中有近 30 天数据 |
